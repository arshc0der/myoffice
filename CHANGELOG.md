# Changelog

## 0.5.0
- **MyExcel:** charts (column, line, area, pie, donut) with hover tooltips, live updates and PNG export; selection statistics in the status bar; Statistics dialog with histogram.
- **MyWord:** document statistics with reading time, Flesch readability and most used words.
- **Launcher:** Office-style start screen with navigation rail, flat tiles and a Recent list with *Date modified*.
- Title bar / status bar use the flat app colour; `IconButton` gained a checked state.
- Fixed: ribbon icons not showing (`iconName` property, `.qrc` path).

## 0.4.0
- MyPowerPoint (slides, shapes, pictures, animations, transitions, slide show, PPTX/PDF/PNG); About, Settings and shortcut dialogs; ruler in MyWord.

## 0.3.0
- MyWord and MyExcel, document tabs, view mode, per-app colours, SVG icon set.
